each is answered in this document.

**A note on numbering.** Each part of this document keeps its own section numbers
(§4.x for estimation, §9.x for testing, and so on), because every cross-reference
in the text — and there are more than eighty — is written against them, and
because four parts each answer more than one examination section. Those internal
numbers therefore do not run consecutively through the document. The banner above
each part states which examination section it satisfies, and this table is the
index.
