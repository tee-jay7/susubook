# Mapping to Examination Requirements

Part A, section 10 of the examination paper lists nineteen required sections. This table shows where
each is answered in this document.

| Exam section | Required section | Where in this document |
|---|---|---|
| 1 | Project title | Title page, and *Problem Definition* Section 1.3 |
| 2 | Problem statement | *Problem Definition* Sections 1.2 to 1.3 |
| 3 | Aim and objectives | *Problem Definition* Sections 1.5 to 1.6 |
| 4 | Stakeholders | *Stakeholder Analysis* Sections 2.1 to 2.6 |
| 5 | Requirements analysis | *Requirements Analysis* Sections 3.1 to 3.8 |
| 6 | SRS | *Software Requirements Specification*, also supplied as `SRS.pdf` |
| 7 | Software effort estimation | *Software Effort Estimation* Sections 4.1 to 4.9 |
| 8 | System analysis | *System Analysis and Design*, Part A (Sections 7.1 to 7.5) |
| 9 | System design | *System Analysis and Design*, Part B (Sections 7.6 to 7.17) |
| 10 | Implementation | *Implementation* Sections 10.1 to 10.8 |
| 11 | Testing | *Testing and Quality Assurance* Sections 9.1 to 9.10, also `Testing_Report.pdf` |
| 12 | Technical debt | *Technical Debt Identification and Management* Sections 8.1 to 8.8, also `Technical_Debt_Plan.pdf` |
| 13 | Deployment | *Deployment* Sections 12.1 to 12.9 |
| 14 | User manual | *SusuBook User Manual*, also `User_Manual.pdf` |
| 15 | Maintenance strategy | *Maintenance Strategy and Future Evolution*, Part A (Sections 11.1 to 11.3) |
| 16 | Future evolution | *Maintenance Strategy and Future Evolution*, Part B (Sections 11.4 to 11.7), including the technical debt repayment plan at Section 11.6 |
| 17 | Limitations | *Limitations, Conclusion and References* Section 17 |
| 18 | Conclusion | *Limitations, Conclusion and References* Section 18 |
| 19 | References | *Limitations, Conclusion and References* Section 19 |

**A note on numbering.** Each part of this document keeps its own section numbers
(Section 4.x for estimation, Section 9.x for testing, and so on). Every cross-reference in the
text is written against those numbers, and four parts each answer more than one
examination section. Those internal
numbers therefore do not run consecutively through the document. The banner above
each part states which examination section it satisfies, and this table is the
index.
